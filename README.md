# pairwise-projectile-hit

子弹穿墙、命中判定延迟、连续射击打不中移动靶：射线只查第一个碰撞；穿透按固定层数；命中用上一帧位置；弹道下坠按固定速度；连续射击不合并查询；移动靶用包围盒中心；后坐力和准星不同步；服务器和客户端命中时间不一致；穿透后伤害不衰减；快速物体 tunneling。game/projectile_hit.py 是核心，tests/test_projectile_hit.py 15个红。要修的是：多层射线；按材质穿透；当前帧插值；弹道积分；批量查询；扫掠包围盒；后坐力预测；服务器回滚；穿透衰减；连续碰撞检测。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
